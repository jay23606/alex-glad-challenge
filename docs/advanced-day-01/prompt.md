# Боевой промпт (один, без уточнений)

Одинаковый текст для обеих генераций. Меняются только правила проекта.

```text
Добавь в проект оценку токенов: core-сервис TokenEstimator и веб-endpoint
POST /api/tokens/estimate. Endpoint принимает JSON { messages: ChatMessage[],
budget?: number } и возвращает общую оценку, разбивку по сообщениям, остаток
бюджета и флаг fits. Оценка — эвристика по UTF-8 байтам (bytes / 4), без новых
зависимостей. Покрой сервис и endpoint тестами. Сделай по правилам проекта.
```

## Почему такой промпт

- Проверяет сразу три слоя: `challenge/src/core` (сервис), `web/` (Route Handler)
  и тесты в двух разных раннерах.
- Оставляет правилам выбор: где экспортировать, как валидировать, как называть
  поля, где хранить zod-схему, как импортировать core в web.
- Не содержит подсказок про `server-only`, `withDb`, chokepoint, `.js`-импорты,
  `no any`, шаблоны тестов — именно это должно прийти из правил.
