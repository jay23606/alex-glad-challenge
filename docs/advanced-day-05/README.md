## Инфраструктура loop'а

- Задачи: GitHub Issues (labels day-3/day-4/day-5 + bug/test/feature/docs/chore).
- После этого пула добавлены процессные метки `P0`–`P3`, `incident`, `hotfix`,
  `in-progress`, `needs-triage`, `blocked` и шаблоны `.github/ISSUE_TEMPLATE/`
  (`AGENTS.md` §13.9).
- Цикл: issue → профиль (§13) → реализация → валидация (typecheck x2 + suite x2 +
  при UI — браузер) → коммит (`fix:`/`test:`/`feat:`/`docs:`/`chore:`) → close с
  комментарием-отчётом → следующая.
- Финальная валидация после пула: challenge 167/167 (node:test), web 254/254
  (vitest, --maxWorkers=2), typecheck обоих пакетов зелёные.
