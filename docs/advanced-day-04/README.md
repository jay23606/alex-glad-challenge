## Рекомендация: для чего хватает локальной

✅ **Достаточно:** точечные фиксы по явному правилу, автокомплит однострочников, переименования/бойлерплейт, вопросы по одному вставленному файлу, работа офлайн и с приватным кодом.
❌ **Незаменимо облако:** генерация фич «под правила проекта» (нужны инструменты + длинный контекст + следование конвенциям), агентные профили (Research/Bug Fix/Граф — весь День 2 невыполним локально), многофайловые правки, ревью диффов.

## Усиление: перебор моделей

На железе 16GB кандидаты ограничены: `qwen3:4b`/`qwen3.5:4b` (инструктуры без FIM-базы — автокомплит хуже), `qwen2.5:7b-instruct` (общий, код слабее coder-версии). `qwen2.5-coder` — целевое семейство; связка 7b(chat)+1.5b-base(FIM) — лучшая доступная без даунлоада >5GB. Попытка перебора на тех же задачах сверх этого — отдельная загрузка моделей; зафиксировано как ограничение, не проделано.
